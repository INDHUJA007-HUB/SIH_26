# Budget and external onboarding

## Role-based ownership

Project/service owner: user/project team (individual designation pending). Budget owner, regulatory approver, process owner, data owner, integration sponsor and production security reviewer must be named before a live pilot. The engineering lead owns artifacts and tracks unresolved gates; it cannot grant itself government API access or legal authority.

| Dependency | Next evidence required | Fallback / gate |

| Docker runtime | Installed/running engine and virtualization prerequisites | Native API works; full container gate pending |
| AICTE records/portal | Schema, sandbox, credentials, data terms, writeback scope | Simulator only |

| Current policy set | Approved complete source/circular set and interpretations | Research drafts disabled |

| AWS deployment | Account, region/features, OIDC role, environment review, budget | Manual deployment workflow remains gated |
| Model/tool rights | Selected weight/binary license and language/template test evidence | Local compatibility spike; no quality claim |

## Cost model template

Monthly cost = API/delivery vCPU-hours + document/media worker hours + Temporal control-plane hours + domain/workflow RDS capacity + object GB-month/requests + backup/archive + telemetry + network/NAT + optional identity/email/provider/model charges.

Inputs: packets/cycle, pages/packet, peak pages/second, measured seconds/page, videos/minutes/codecs, retention months, object/derivative multiplier, source calls/claim, supported institutions and report volume. Owner enters current approved regional rates; report total and cost/page, packet, media minute and authoritative source resolution. No unverified rupee estimate is asserted. Quotas, trace retention, capped samples and non-production idle schedules are engineering controls, not permission to delete retained evidence.
