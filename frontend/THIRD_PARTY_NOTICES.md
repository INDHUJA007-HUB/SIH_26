# React Bits components

CardNav and SwarmCursor were integrated from the complete JavaScript/CSS source supplied by the user, from React Bits:

- https://www.reactbits.dev/components/card-nav
- https://www.reactbits.dev/animations/swarm-cursor
- Upstream repository: https://github.com/DavidHDev/react-bits

Local adaptations: NiyamFlow palette/content; existing Lucide arrow icon in place of Hugeicons; explicit menu button labels and inert collapsed navigation; typed public props; desktop-only lazy mounting; preserved system cursor; reduced-motion and touch exclusion; fixed pointer-transparent cursor layer with document-level hover targets.
